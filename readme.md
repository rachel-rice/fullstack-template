# My Full Stack Template Project
My basic full stack template with MVC structure. It's a good basic starting point for projects.

This template is not hosted, running locally on port 3000.

<!-- ![alt tag](http://urlforimagesgohere.com) -->

## How It's Made:

**Tech used:** HTML, CSS, JavaScript, Node.js, MongoDB

Started with a basic full stack app and evolved it into a full stack template. Added MVC structure.

**Dependencies:** ejs, express, mongoose, morgan, dotenv, cors

## Install:
npm install

## Run
npm start
